= Reference Documents

PDFs in this directory are gitignored. Download them with:

  curl -L -o riscv-privileged-20241017.pdf \
    "https://tools.cloudbear.ru/docs/riscv-privileged-1.13-20241017.pdf"

  curl -L -o rp2350-datasheet.pdf \
    "https://datasheets.raspberrypi.com/rp2350/rp2350-datasheet.pdf"

  curl -L -o esp32-c3-technical-reference.pdf \
    "https://cdn.sparkfun.com/assets/9/1/2/7/8/esp32-c3_technical_reference_manual_en.pdf"
